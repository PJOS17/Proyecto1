=== GUÍA DE USO - INTÉRPRETE DE BITCOIN SCRIPT ===

1. COMPILACIÓN
   Ejecuta en la terminal (doble clic):
   compilar.bat

2. MODO INTERACTIVO (REPL)
   java -cp "target\classes" com.bitcoin.Main
   (O ejecutar: run_interactive.bat)

3. EJEMPLO DE USO (Dentro del programa)
   Una vez iniciado, verás el prompt ">". Prueba lo siguiente:

   > OP_1
     (Salida esperada: Stack: [0x01])

   > OP_2
     (Salida esperada: Stack: [0x01, 0x02])

   > OP_ADD
     (Salida esperada: Stack: [0x03])

   > 5
     (Salida esperada: Stack: [0x03, 0x05])

   > OP_GREATERTHAN
     (Salida esperada: Stack: [0x00] -> FALSO, porque 3 no es mayor que 5)

4. DEMOSTRACIONES OBLIGATORIAS (Fase 2)

   a) P2PKH CORRECTO:
      java -cp "target\classes" com.bitcoin.Main --p2pkh --trace

   b) P2PKH INCORRECTO (clave incorrecta, debe fallar):
      java -cp "target\classes" com.bitcoin.Main --p2pkh-bad --trace

   c) OP_IF / OP_ELSE / OP_ENDIF:
      java -cp "target\classes" com.bitcoin.Main --demo-if --trace

   d) MULTISIG 2 de 3 (OP_CHECKMULTISIG):
      java -cp "target\classes" com.bitcoin.Main --demo-multisig --trace

   e) TODAS LAS DEMOS A LA VEZ:
      java -cp "target\classes" com.bitcoin.Main --demo-all

5. COMANDOS ÚTILES (dentro del REPL)
   - trace on   : Activa el modo detallado (ver pila tras cada paso).
   - trace off  : Desactiva el modo detallado.
   - clear      : Limpia toda la pila (reinicia).
   - exit       : Salir del programa.

6. EJECUTAR UN SCRIPT COMPLETO
   java -cp "target\classes" com.bitcoin.Main --trace "1 2 OP_ADD 5 OP_GREATERTHAN"

7. LISTA DE COMANDOS (OPCODES) DISPONIBLES

   Constantes:
   - OP_0 / OP_FALSE : Empuja 0 (array vacío) a la pila.
   - OP_1 .. OP_16   : Empuja el número correspondiente (1 al 16).
   - <número>        : Cualquier número (ej. "5", "-99") se empuja automáticamente.
   - <hex>           : Cualquier hex (ej. "0xFF") se empuja como bytes.

   Pila:
   - OP_DUP          : Duplica el elemento superior.
   - OP_DROP         : Elimina el elemento superior.
   - OP_SWAP         : Intercambia los dos elementos superiores.
   - OP_OVER         : Copia el segundo elemento y lo pone arriba.

   Lógica:
   - OP_EQUAL        : Retorna TRUE si los dos topes son iguales.
   - OP_EQUALVERIFY  : Igual que OP_EQUAL, pero falla si no son iguales.
   - OP_VERIFY       : Falla si el tope es falso.
   - OP_NOT          : Invierte el valor booleano.
   - OP_BOOLAND      : AND lógico.
   - OP_BOOLOR       : OR lógico.

   Aritmética:
   - OP_ADD          : Suma los dos números superiores.
   - OP_SUB          : Resta los dos números superiores.
   - OP_LESSTHAN     : Verdadero si a < b.
   - OP_GREATERTHAN  : Verdadero si a > b.
   - OP_NUMEQUALVERIFY : Falla si los números no son iguales.

   Criptografía (Simulada):
   - OP_SHA256       : Aplica SHA-256 al tope.
   - OP_HASH160      : Aplica SHA256 -> SHA1 (simula RIPEMD160) al tope.
   - OP_HASH256      : Aplica SHA256 -> SHA256 al tope.
   - OP_CHECKSIG     : Verifica firma (simulado).
   - OP_CHECKSIGVERIFY : Igual que CHECKSIG, pero falla si es inválido.
   - OP_CHECKMULTISIG : Verifica M-de-N firmas (simulado).

   Control de Flujo:
   - OP_IF           : Ejecuta el bloque si el tope es verdadero.
   - OP_NOTIF        : Ejecuta el bloque si el tope es falso.
   - OP_ELSE         : Rama alternativa.
   - OP_ENDIF        : Fin del bloque condicional.
   - OP_RETURN       : Marca el script como inválido inmediatamente.
